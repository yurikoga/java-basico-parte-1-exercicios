# ☕ Java Básico — Fundamentos (Parte 1)

Repositório dedicado às resoluções dos exercícios práticos da disciplina de Java Básico, utilizando o **IntelliJ IDEA**. Esta etapa contempla os **10 primeiros exercícios** da apostila *Java Básico - Guia Didático Universitário*, focados na sintaxe inicial e manipulação de tipos na linguagem.

## 📋 Exercícios Resolvidos

| Classe | Tema | Descrição |
| :--- | :--- | :--- |
| `Exercicio01` | Tipos de dados | Declaração e exibição de variáveis (`String`, `int`, `double` e `boolean`). |
| `Exercicio02` | Operações numéricas | Cálculo de soma, subtração, multiplicação, divisão inteira e resto (`%`). |
| `Exercicio03` | Caracteres (`char`) | Armazenamento e exibição de identificador de turma usando tipo `char`. |
| `Exercicio04` | Valores lógicos | Declaração e impressão de estado booleano (`sistemaOnline`). |
| `Exercicio05` | Strings | Concatenação de nome e sobrenome em uma única saída. |
| `Exercicio06` | String + Números | Demonstração da precedência entre concatenação textual e soma aritmética. |
| `Exercicio07` | Caracteres de escape | Uso de `\n`, `\\` e `\"` para formatação de caminhos e citações no console. |
| `Exercicio08` | Widening Casting | Conversão automática (implícita) de `int` para `double`. |
| `Exercicio09` | Narrowing Casting | Conversão explícita de `double` para `int` e análise do truncamento decimal. |
| `Exercicio10` | Operadores de atribuição | Atualização incremental de pontuação utilizando `+=` e `-=`. |
